### FAQ

**How do I install musfiraai-cli?**  
Run npm install -g musfiraai-cli to install the CLI globally.

**How do I request a new tool or automation?**  
Execute musfiraai request and follow the interactive prompts to describe your needs.

**How can I check the status of my requests?**  
Run musfiraai status you@email.com to view all requests and their current status.

## Install

```
npm install -g musfiraai-cli
```

## Use

```
musfiraai request
```
Walks you through describing what you need. No cost, no invoice.

```
musfiraai status you@email.com
```
Shows every request you've made and its current status (Pending / In Progress / Done / Rejected).
