# musfiraai-cli

Request free custom tools, automations, AI agents, and n8n workflows from Musfiraai — right from your terminal.

## Install

```
npm install -g musfiraai-cli
```

## Use

```
musfiraai request
```
Walks you through describing what you need. No cost, no invoice.

```
musfiraai status you@email.com
```
Shows every request you've made and its current status (Pending / In Progress / Done / Rejected).

## Publishing (for Musfiraai team only)

```
npm login
npm publish
```
